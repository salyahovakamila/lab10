* Интеграция сгенерированного пользовательского интерфейса с API.

### Приложение: Frontend-часть

Согласно условиям задания, минималистичный Frontend (`index.html`) был разработан с помощью LLM. 

**Использованный промпт для генерации:**
> «Напиши простой пользовательский интерфейс в одном HTML-файле со встроенным CSS и чистым Vanilla JS. Интерфейс должен взаимодействовать с локальным API на FastAPI (http://127.0.0.1:8000). 
> Реализуй три визуальных блока: 
> 1. Форма загрузки файла .pkl (отправляет POST на /upload-model). 
> 2. Форма ввода индивидуальных данных клиента: Пол (select), В браке (select), Высшее образование (select), Доход (input), Сумма кредита (input), Кредитная история (select). По кнопке отправляет JSON (POST на /predict) и выводит вердикт (ОДОБРЕНО/ОТКАЗ). 
> 3. Форма загрузки файла CSV для пакетной обработки (POST на /predict-from-csv) с выводом JSON-ответа на экран. 
> Сделай дизайн аккуратным, добавь обработку ошибок (catch), чтобы код выглядел так, как его написал бы человек без лишних усложнений.»
